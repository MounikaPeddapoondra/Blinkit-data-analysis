# Blinkit Data Analysis Project

## 📊 Overview
This project analyzes Blinkit sales data using Python.

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📈 Key Insights
- Total Sales: $1.2M+
- Average Sales: $141
- Average Rating: 4.0

## 📊 Analysis Performed
- Sales by Fat Content
- Sales by Item Type
- Sales by Outlet Location
- Sales by Outlet Size
- Sales Trend by Year

Charts are included in the repository.
